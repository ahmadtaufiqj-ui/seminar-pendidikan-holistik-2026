## 🏗️ Ciri-Ciri Utama Sistem (Mod B — Live Collaborative)
1. **Google Sheets sebagai Pangkalan Data Masa Nyata:**
   Semua Ketua Portfolio dan AJK boleh mengemas kini status tugas masing-masing secara langsung melalui Google Sheets (`SELESAI`, `SEDANG BERJALAN`, `BELUM MULA`).
2. **Auto-Sinkronisasi Tanpa Server:**
   Dashboard web membaca data terus daripada Google Sheets menggunakan Google Visualization API secara automatik tanpa memerlukan server tambahan.
3. **Formulasi Kemajuan Saintifik (Bukan Anggaran):**
   Peratusan kemajuan dikira berdasarkan nisbah penyempurnaan daripada 128 senarai semak tindakan rasmi.
4. **Pemantau Realiti Kewangan & Belanjawan:**
   Memaparkan kedudukan dana pasti (RM11,000) berbanding anggaran perbelanjaan (RM27,200) serta memantau jurang dana semasa (RM16,200).
5. **Penapis & Carian Tugasan Interaktif:**
   Membolehkan tapisan pantas mengikut 10 portfolio unit, fasa kerja, dan status tindakan.
